# Lorem Ipsum Generator for Zee

A lightweight Lua plugin to generate and insert Lorem Ipsum placeholder text into documents.

## Commands

- `lorem_sentence`: Inserts a single Latin placeholder sentence.
- `lorem_paragraph`: Inserts a standard 5-sentence placeholder paragraph.
- `lorem_paragraphs_3`: Inserts three paragraphs of placeholder text.

## Installation

Run in Zee command mode:
```text
:plugin install lorem-ipsum
```
Or place this folder into `~/.config/zee/plugins/lorem-ipsum/`.
